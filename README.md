# 3D Heures ⏱️

Application Progressive Web App (PWA) épurée et moderne conçue pour le suivi du temps de travail des techniciens applicateurs dans le domaine de la 3D (Dératisation, Désinfection, Désinsectisation).

## Fonctionnalités

- ⚡ **Saisie rapide journalière** : Date, heure de début, heure de fin, pause déduite automatiquement, note optionnelle.
- 📊 **Tableau de bord des cumuls** : Calcul instantané en temps réel des heures quotidiennes, hebdomadaires, mensuelles et annuelles.
- 🔢 **Convertisseur centièmes / décimal** : Conversion bidirectionnelle (ex. 1h30 ↔ 1,50h) pour remplir les fiches d'intervention papier sans calcul mental.
- 📋 **Historique & Filtres** : Consultation par mois, modification rapide et suppression avec confirmation.
- 🛡️ **Sauvegarde & Partage Android** : 
  - Rappel automatique en fin de mois (à partir du 25).
  - Partage 1-clic via le menu natif Android (Google Drive, E-mail, WhatsApp...).
  - Import et restauration avec fusion sans doublons.
- 📲 **Progressive Web App (PWA) & Mode Hors-ligne** :
  - Installable directement sur l'écran d'accueil Android sans passer par le store.
  - Fonctionne à 100% hors-ligne (en sous-sol, parking, cave) grâce au Service Worker.
